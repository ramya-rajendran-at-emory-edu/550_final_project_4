# 550_final_project_4

## 📊 Cancer Mortality Analysis (2020–2021)

This project analyzes U.S. provisional cancer death data from 2020 to 2021, sourced from the CDC. The analysis explores cancer mortality trends by year, month, cancer type, sex, and race/ethnicity.

## 📑 About the Final Report

The final report, `final_project_analysis.html`, is generated from the R Markdown file:
```
analysis/final_project_analysis.Rmd
```

It provides a comprehensive analysis of provisional cancer mortality data in the U.S. (2020–2021), focusing on:

- **Monthly and yearly trends** in total cancer deaths
- **Demographic disparities** by sex and race/ethnicity
- **Top cancer types** contributing to mortality
- **Summary statistics** by cancer type

The report is rendered using the script:
```
scripts/03_render_report.R
```

## 📋 Final Report Contents

Below is a brief overview of each component in the final report:

- **Summary of Cancer Deaths by Cancer Type**  
  The table below provides a comprehensive overview of total cancer-related deaths for different cancer types recorded in the dataset. It specifically focuses on cancer types that contain the terms “malignant” or “unspecified”, ensuring that the analysis captures the most relevant data on cancer mortality.

- **Monthly and yearly trends in total cancer deaths**  
  A line chart visualizing cancer deaths across months in 2020 and 2021, highlighting seasonal or temporal fluctuations in overall mortality.

- **Total Deaths by Year (2020 vs. 2021)**
  A bar plot that compares cancer death counts across race/ethnicity groups, separated by sex. This illustrates disparities in cancer mortality across demographic lines.

- **Deaths by Demographic Group (Sex × Race/Ethnicity)**
  This bar plot analysis explores total cancer deaths by sex and race/ethnicity. It begins by selecting relevant columns related to cancer mortality, sex, and racial/ethnic groups
 
- **Top 5 Cancer Types by Deaths**
  This analysis identifies and visualizes the top 5 cancer types by total death counts. The dataset is filtered to include only columns related to malignant and unspecified cancer deaths.

## 🚀 How to Run This Project

Install the required packages:

```r
install.packages(c("tidyverse", "lubridate", "scales", "kableExtra", "here", "rmarkdown", "yaml"))
```

### 🔹 Option 1: Run scripts manually

- **📄 Required Table**: `scripts/01_create_table.R`
- **📊 Required Figures**: `scripts/02_create_figure.R`
- **📑 Final Report**: `scripts/03_render_report.R` → output saved as `analysis/final_project_analysis.html`

To run manually:

```r
source("scripts/01_create_table.R")
source("scripts/02_create_figure.R")
source("scripts/03_render_report.R")
```

Use `03_clean_output.R` (if available) to remove old output files before regenerating.


### 🔹 Option 2: Use the Makefile (Linux/macOS/WSL)

The project includes a `Makefile` to automate the entire analysis pipeline. From the terminal, you can run:

```bash
make
```

This will:
- Generate the summary table (`scripts/01_create_table.R`)
- Generate all required plots (`scripts/02_create_figure.R`)
- Render the final HTML report (`scripts/03_render_report.R`)

Other available options:

| Command         | Action                                      |
|-----------------|---------------------------------------------|
| `make table`    | Generate only the summary table             |
| `make figures`  | Generate only the figures                   |
| `make clean`    | Remove all `.html` and `.png` outputs       |


### 🔹 Option 3: Restore the R Package Environment (Recommended)

This project uses the [`renv`](https://rstudio.github.io/renv/) package for reproducibility.

To restore the environment:

```bash
make install
```

Or run manually in R:

```r
renv::restore()
```

Make sure you're in the project root directory (`550_final_project_4/`) before running `make`.
